# Campus Life Super App
This project creates a unified web platform that addresses common pain points for college students, particularly commuters. The app consolidates essential campus information into a single, easy-to-access interface, featuring:

- Dining Services: Real-time cafeteria hours and daily menus
- Coffee Shops: Campus coffee shop locations, hours, and menu offerings
- Weather & Campus Updates: Current weather conditions and important campus announcements

By bringing together these key resources, the app helps students plan their day more efficiently and stay informed about campus life.

# Technologies used
- HTML
- CSS
- Bootstrap
- JavaScript
- External Weather API
- Claude.AI
- Visual Studio

# Overview of features and how to use them
## Home Page
Contains three tabs to navigate to.
1. Edwards Commons
2. The Salty Dog
3. Weather & Daily Info Page

## Edwards Commons

- View today's cafeteria menu
- Check operating hours for all dining locations
- Includes a public feedback area where you can see what other students think about today's food

## The Salty Dog

- View current and seasonal menu items and pricing
- See current hours and availability

## Weather & Daily Info Page

- Real-time weather conditions
- Important campus announcements
- Service status updates (library hours, gym closures, etc.)
- Contains an application that only admins can use to send a campus update

## How to Navigate
- Home Page:
Contains three tabs to navigate to.
1. Edwards Commons
2. The Salty Dog
3. Weather & Daily Info Page

- Edwards Commons: Navigate between tabs at the top.
  1. Home Page - Takes you to the home page
  2. Cafeteria - Takes you to the Edwards Commons page
  3. Coffee Shop - Takes you to The Salty Dog page
  4. Weather & Daily Info Page - Takes you to the Weather & Daily Info Page
